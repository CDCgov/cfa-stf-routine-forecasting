# Indoor-activity seasonality knots

`indoor_activity_climatology.csv2` is a model-science artifact from `cdcent/cfa-mech-experiment`; it is not fitted or generated by the routine forecasting pipeline.
The upstream fit was derived from the county-level indoor-activity data published by Susswein, Rest, and Bansal:

> Susswein Z, Rest EC, Bansal S.
> *Disentangling the rhythms of human activity in the built environment for airborne transmission risk: An analysis of large-scale mobility data.* *eLife* 12:e80466 (2023).
> <https://doi.org/10.7554/eLife.80466>

Their data and analysis code are available at <https://github.com/bansallab/indoor_outdoor>.
`cfa-mech-experiment` pins that source at commit `87184959db3aeefad077d0320ef14388b19aa635`; its climatology README records the complete source-file provenance and derivation.

The file contains the 52 fitted knot values of a repeating annual indoor-activity curve for each U.S. state, the District of Columbia, and the national `us` series.
Its columns are:

- `location`: lowercase USPS abbreviation, or `us`;
- `knot`: annual knot number, 1–52;
- `value`: dimensionless, location-specific knot value, normalized to an annual mean of 1.

At runtime, `ConfigurableEpi` constructs a periodic cubic spline through these knots.
The CSV therefore contains the fitted curve's knot points, not raw mobility observations or daily model inputs.
The production model scales the resulting curve with its fixed `kappa = 0.8`.

## Interpretation

The curve is an indoor-activity forcing proxy, not an observation of transmission.
See the upstream README for aggregation and normalization details, coverage limitations, and modelling assumptions.
